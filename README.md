## ⚡ النشر المباشر على Vercel (من GitHub إلى Vercel)

هذا المستودع مهيأ بملف `vercel.json` وبنية ثابتة (Static Web App) خفيفة وسريعة جدًا تعمل 100% على باقة Vercel المجانية (Hobby) دون أي تكاليف أو حدود دوال معقدة.

### خطوات النشر:

1. **الربط مع Vercel**:
   - ادخل على [لوحة تحكم Vercel](https://vercel.com/dashboard).
   - اضغط على **Add New...** ثم **Project**.
   - اختر مستودع **`y5747m-gif/yaseen868-`** واضغط **Import**.
   - أو افتح الرابط المباشر: [استيراد إلى Vercel مباشرة](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fy5747m-gif%2Fyaseen868-)
2. **النشر التلقائي (Zero-Config)**:
   - اضغط **Deploy** مباشرة دون الحاجة لتغيير أي إعدادات أو إضافة متغيرات بيئية.
   - خلال ثوانٍ معدودة ستحصل على رابط حي لموقعك ينتهي بـ `.vercel.app`.
3. **التحديث المستمر (CI/CD)**:
   - بمجرد دمج التعديلات في فرع `main` على GitHub، تقوم منصة Vercel بإعادة بناء ونشر الموقع تلقائياً في ثوانٍ.

## 🌟 مميزات Mokta AI 3D

- 🧠 **محرك مستقل بالكامل**: لا يعتمد على ChatGPT أو OpenAI أو خوادم GPU باهظة؛ خط المعالجة بالكامل مكتوب بخوارزميات رؤية حاسوبية وهندسة ثلاثية الأبعاد تعمل على متصفح العميل مباشرة.
- 📸 **تحليل الصورة والاكتشاف الذكي**:
  - فحص حدة الصورة، اتجاه الإضاءة، وحساب البعد البؤري المقدر للكاميرا ($f_x$).
  - اكتشاف الأجسام باستخدام تقنيات SLIC Superpixels وتحديد البروز (Saliency Detection).
  - تصنيف نوع العنصر (منتج، تمثال، عنصر طبيعي، أثاث، إلخ).
- ✂️ **عزل دقيق وخلفية نظيفة**:
  - تقنيات Trimap + Gaussian Mixture Models (GMM) + Local Color-Line Matting.
- 📐 **تقدير العمق متعدد الإشارات (Multi-cue Depth)**:
  - دمج إشارات التظليل (Shape-from-Shading)، والتركيز (Defocus/Blur gradient)، وحجم الإسقاط.
- 🔬 **وضع التفاصيل الدقيقة (Detailed — الافتراضي)**:
  - طبقة تفاصيل عالية التردد (HF Detail Layer) تُستعاد من التظليل وتُضاف إلى خريطة العمق (حزوز، نقوش، حواف صغيرة) مع إخماد حواف الخامة حتى لا تتحوّل الطباعة إلى نتوءات.
  - شبكة TSDF أدق (حتى 1.2× من دقة مستوى الجودة) مع عيّنة ثنائية الخطية للسطح الأمامي بدل متوسط المساحة، وبدون تنعيم يمحو التفاصيل.
  - خريطة نواميس (Normal Map) تضمّ التفاصيل الدقيقة من الصورة نفسها فوق ناموس الوجه.
  - حماية طوبولوجية للشبكات الدقيقة: شبكة مغلقة (Watertight) ومانيفولد حتى عند Ultra.
- 🌐 **إعادة البناء الحجمي (Volumetric 3D)**:
  - تحويل إلى سحابة نقطية (Point Cloud) ثم دمج حجمي بحقل مسافات مقطوع (TSDF).
  - استخراج المضلعات بخوارزمية Marching Tetrahedra لضمان شبكة مجسمة محكمة ومغلقة من الأمام والخلف.
- 🎨 **أطلس UV وخامات PBR حقيقية**:
  - تسطيح وحزم مخططات UV تلقائياً.
  - خبز خريطة الألوان الأساسية (Albedo) مع إزالة الإضاءة الموجهة.
  - توليد خرائط النواميس (Normal Maps) والخشونة والمعدنية (ORM - AO / Roughness / Metalness).
- 📦 **دعم كل صيغ التصدير الشائعة**:
  - **GLB / glTF 2.0**: للمواقع، الواقع المعزز (AR)، والألعاب.
  - **OBJ + MTL**: للبرامج الهندسية مثل Blender وMaya و3ds Max.
  - **STL**: جاهز للطباعة ثلاثية الأبعاد (3D Printing).
  - **PLY**: شبكة مضلعات ملونة وسحابة نقطية.
  - **ZIP**: حزمة كاملة تحتوي النموذج والخرائط وتقرير التحليل المفصل JSON.
- 👁️ **عارض ثلاثي الأبعاد WebGL تفاعلي**:
  - دوران 360 درجة، تقريب، إضاءة تفاعلية، تحكم في الخلفية وشبكة الإحداثيات (Wireframe).
  - واجهة عربية أنيقة تدعم الوضع الليلي والنهاري (Dark / Light Theme).

## 🚀 التشغيل المحلي (Local Development)

```bash
# 1) استنساخ المستودع
git clone https://github.com/y5747m-gif/mokta-ai-3D.git
cd mokta-ai-3D

# 2) تشغيل الخادم المحلي
npm start
# سيفتح الخادم على الرابط: http://localhost:3000

# 3) تشغيل الاختبارات الآلية (11 اختبار شامل)
npm test
```
