# يومي | YAWMI — المخطط الذكي للطالب

تطبيق ويب تقدمي (PWA) عربي RTL للطالب الأزهري (الصف الثاني الثانوي، القسم الأدبي).
لا يحتاج حسابًا ولا إنترنتًا بعد التحميل، ولا يحتوي على أي مفاتيح API.

## التشغيل
- محليًا: `cd yawmi && python3 -m http.server 8080` ثم افتح http://localhost:8080
- الاختبارات: `npm run test:yawmi` (من جذر المستودع، تستخدم `node:test`)

## البنية
| الملف | الدور |
|---|---|
| `index.html` | الغلاف والتنقل السفلي (الرئيسية، الجدول، المذاكرة، المنبهات، حسابي) |
| `js/core.js` | منطق خالص: الوقت، التكرار، التعارضات، التذكيرات، الترحيل، المساعد |
| `js/app.js` | الواجهة، المؤقت، المنبهات، التخزين، النسخ الاحتياطي |
| `css/app.css` | التصميم: الوضع الفاتح/الداكن، RTL، تقليل الحركة |
| `sw.js` | تخزين مؤقت للعمل بدون إنترنت، والتعامل مع نقرات الإشعارات |
| `tests/core.test.mjs` | 25 اختبارًا لمنطق الجدول والتذكيرات والترحيل |

## التخزين
- `localStorage` بمفتاح `yawmi:v1` مع رقم إصدار ومسار ترحيل (`migrate`).
- عند تلف البيانات تُحفظ نسخة احتياطية تلقائيًا قبل البدء ببيانات افتراضية.
- إن كانت البيانات من إصدار أحدث يفتح التطبيق للقراءة فقط.
- تصدير/استعادة JSON من «حسابي». الاستعادة تطلب تأكيدًا.

## حدود مهمة للمنبهات (PWA)
- المتصفح لا يضمن منبهًا دقيقًا عند إغلاق التطبيق أو قفل الهاتف أو توفير الطاقة.
- المنبهات تُطلق بدقة حين يكون التطبيق مفتوحًا (أو في الخلفية حسب المتصفح)، مع نافذة تأخير 10 دقائق؛ أي تنبيه فات وقته يُسجَّل «فائتًا» ولا يُطلق متأخرًا.
- الإشعارات تحتاج إذن المستخدم؛ بدونه تظهر التنبيهات داخل التطبيق فقط وتُعرض الحالة بوضوح.
- للحصول على منبهات Android الدقيقة (AlarmManager) يلزم تغليف التطبيق بإطار أصلي (مثل Capacitor) وإضافة أذونات الإنذار الدقيق؛ هذا خارج نطاق هذا الإصدار.

## ما هو مُنفَّذ
- الجدول الأصلي للطالب محمّل كما ورد (السبت–الجمعة)، والحصة الشرعية الاختيارية يوم الخميس غير مؤكدة افتراضيًا.
- أحداث متكررة ولمرة واحدة، تعديل/نسخ/حذف، كشف التعارضات، بحث وتصفية، تنقل بين الأسابيع.
- مؤقت تركيز (50/10 مع استراحة طويلة بعد عدد من الجلسات)، تسجيل نتيجة الجلسة، إحصاءات.
- مواد قابلة للتعديل (أسماء، ألوان، أولوية، نقاط ضعف، امتحانات)، مهام بخطوات وتكرار، مراجعة متباعدة قابلة للضبط.
- منبهات (إضافة/تعديل/حذف/تجربة/غفوة/إيقاف/تم)، تذكيرات الحصص المشتقة (60/30/15 دقيقة + التحرك + البداية)، سجل.
- عادات، قائمة تحضير ليلي، تحذير من قلة النوم والحمل المرتفع، مركز إشعارات.
- مساعد قائم على القواعد يقرأ بياناتك الحقيقية ولا يغيّر الجدول إلا بموافقتك.

## ما هو غير مُنفَّذ بعد
- واجهة عربية فقط (لا يوجد تبديل لغة).
- مرفقات المهام وتزامن السحابة.
- مساعد بالذكاء الاصطناعي عبر خادم (المساعد الحالي قواعدي ويعمل دون إنترنت).
